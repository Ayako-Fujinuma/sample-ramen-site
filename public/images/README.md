# 画像素材について

架空店舗「麺処 ぬくもり庵」用の写真(AI生成のサンプル画像)です。全6サンプルで共通して使っています。
実店舗で使う際は、以下のファイルと同じ名前で実際の写真に差し替えてください。ファイル名を変える場合は各HTMLファイル内の該当 `src` / `background-image` も合わせて書き換えてください。

| ファイル名 | 用途 | 推奨サイズ・比率の目安 |
| --- | --- | --- |
| `hero-bg.jpeg` | トップのヒーロー背景(店内 or 看板の一枚) | 横長 1600×900 程度、明るく清潔感のあるカット |
| `menu-shoyu.jpeg` | メニュー「特製醤油ラーメン」の写真 | 正方形 600×600 程度 |
| `menu-shio.jpeg` | メニュー「塩ラーメン」の写真 | 正方形 600×600 程度 |
| `menu-miso-butter-corn.jpeg` | メニュー「味噌バターコーン」の写真 | 正方形 600×600 程度 |
| `menu-tsukemen.jpeg` | メニュー「特製つけ麺」の写真 | 正方形 600×600 程度 |
| `menu-veggie.jpeg` | メニュー「野菜たっぷり塩そば」の写真 | 正方形 600×600 程度 |

SNSアイコン(Instagram/X)はHTML内に直接インラインSVGで埋め込んでいるため、このフォルダに画像ファイルはありません。ブランドロゴを使う場合は `public/index.html` 内の `<svg class="icon-sns">` 部分を差し替えてください。
