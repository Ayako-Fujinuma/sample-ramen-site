# 画像素材について

このフォルダの `.svg` はすべて**実写真が用意できるまでの仮プレースホルダー**です(グラデーション+シンプルな器イラスト)。
実店舗で使う際は、以下のファイルと同じ名前で写真(jpg/webp推奨)に差し替えてください。ファイル名を変える場合は `public/index.html` 内の該当 `src` も合わせて書き換えてください。

| ファイル名 | 用途 | 推奨サイズ・比率の目安 |
| --- | --- | --- |
| `hero-bg.svg` | トップのヒーロー背景(店内 or 看板の一枚) | 横長 1600×900 程度、明るく清潔感のあるカット |
| `menu-shoyu.svg` | メニュー「特製醤油ラーメン」の写真 | 正方形 600×600 程度 |
| `menu-shio.svg` | メニュー「塩ラーメン」の写真 | 正方形 600×600 程度 |
| `menu-miso-butter-corn.svg` | メニュー「味噌バターコーン」の写真 | 正方形 600×600 程度 |
| `menu-tsukemen.svg` | メニュー「特製つけ麺」の写真 | 正方形 600×600 程度 |
| `menu-veggie.svg` | メニュー「野菜たっぷり塩そば」の写真 | 正方形 600×600 程度 |

SNSアイコン(Instagram/X)はHTML内に直接インラインSVGで埋め込んでいるため、このフォルダに画像ファイルはありません。ブランドロゴを使う場合は `public/index.html` 内の `<svg class="icon-sns">` 部分を差し替えてください。
